# Journaux de session

Un dossier par membre. On y dépose les transcriptions **brutes** produites par son agent,
sans les retoucher : c'est ce qui atteste la contribution personnelle de chacun.

Où les trouver :

- **Cline** (VS Code) : historique des tâches de Cline, puis exporter chaque tâche
  (bouton d'export de la tâche) en Markdown.
- **Claude Code** : fichiers `.jsonl` dans `~/.claude/projects/<dossier du projet>/`.
- **Codex** : fichiers de session dans `~/.codex/sessions/`.

Copier les fichiers tels quels dans `sessions/<prénom>/`. Ne pas les résumer, ne pas les
nettoyer, ne pas en écrire à la main.
